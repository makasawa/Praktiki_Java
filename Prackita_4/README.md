# Практическая работа 4 — вариант 28 «Медиатека»

Консольное приложение Java без generics, готовых коллекций, Stream API и лямбда-выражений.
Реализованы фильмы, сериалы, музыкальные альбомы и видеоигры; массив объектов базового типа
`MediaItem`; оценки и отзывы; поиск, избранное, плейлисты, статистика и CRUD.

Запуск:
```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```
