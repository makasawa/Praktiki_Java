# Практическая работа 7. Карточки слов

В документе приведены задания 1–10. Для номера 28 выбран вариант 8 по последней цифре. На первом экране выберите набор, затем добавьте слова вручную или импортируйте текстовый файл UTF-8. Каждая строка содержит слово и перевод, разделённые знаком равенства.

    apple = яблоко
    road = дорога

Тренировка перемешивает карточки выбранного набора. При вводе ответа появляется цветовая оценка. Пометка «выучено» сохраняется вместе с карточками во внутреннем хранилище. Системный диалог выбора файла предоставляет доступ к выбранному документу.
