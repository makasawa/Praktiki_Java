# Практическая работа 6. Краска для комнаты

Вариант 28. Два экрана на Java с XML-разметкой и findViewById. Размеры комнаты вводятся в метрах. Расчёт учитывает четыре стены, расход составляет 0,1 л на квадратный метр.

## Проверочные примеры

| Длина × ширина × высота | Ожидаемый результат |
|---|---|
| 4 × 3 × 2,5 | 35 м² и 3,5 л |
| 5 × 5 × 3 | 60 м² и 6 л |
| Пустое поле или ноль | Ошибка ввода |
| Переход на второй экран | Площадь и расход совпадают с первым экраном |
| Возврат кнопкой «Назад» | Введённые размеры сохраняются |

## Ответы на контрольные вопросы

1. Activity управляет экраном. Метод setContentView загружает XML, а идентификаторы связывают код с отдельными View.
2. findViewById ищет элемент по идентификатору при выполнении. ViewBinding генерирует класс со ссылками на элементы после включения buildFeatures.viewBinding в Gradle.
3. Для android:onClick у Activity должен быть открытый метод с указанным именем, одним аргументом View и результатом void.
4. Явный Intent задаёт класс Activity. Неявный описывает действие и данные, а подходящее приложение выбирает Android.
5. Второй аргумент getIntExtra задаёт значение по умолчанию, если подходящего параметра нет.
6. Если Activity отсутствует в манифесте, запуск может закончиться ActivityNotFoundException.
7. finish закрывает текущий экран и возвращает предыдущий из стека. Новый startActivity добавил бы ещё один экземпляр.
8. Второй экран может вызвать setResult и finish. Первый заранее регистрирует обработчик результата, чтобы система смогла доставить его и после пересоздания Activity.
